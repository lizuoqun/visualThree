# 目录说明

| 文件/文件夹  | 描述                           |
|---------|------------------------------|
| assets  | 存放项目所需的静态资源文件，如模型、图片、js包源码等。 |
| light   | 光照效果相关代码案例。                  |
| matrix  | 矩阵变换、三维世界相关代码案例。             |
| plane   | 包含与平面相关的代码文件或资源。             |
| texture | 存放项目所需的纹理文件，如贴图、材质等。         |
